# 🎵 Spotify Clone

A responsive Spotify Web Player Clone built using **HTML** and **CSS**.

---

## 🚀 Features

- 🎧 Responsive Spotify UI
- 📂 Sidebar Navigation
- 🎵 Music Player
- 📀 Album Cards
- 🔍 Search Section
- 📱 Sticky Navigation
- 🎨 Modern UI Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts (Montserrat)
